GET STARTED

把 JevLens 放进浏览器。

  1. 下载插件，解压即可

    已编译好，无需安装 Node.js 或运行命令。下载后先解压 ZIP。

    下载 JevLens v0.1.0 · Chrome ZIP ↓
  2. 加载 Chrome 扩展

    在电脑上打开 chrome://extensions，开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择解压后包含 manifest.json 的文件夹。保留这个文件夹，不要删除。

  3. 打开网页，开始探索

    刷新网页，点击工具栏 JevLens。Demo 可直接体验；真实 AI 分析可在 API settings 配置 Jev 或 OpenRouter。

目前为手动安装版，尚未上架 Chrome 插件商店。更新时请重新下载并加载新版。
