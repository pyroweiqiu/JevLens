START HERE / 01

一个在浏览器里陪你阅读的助手。

JevLens 是 Chrome 浏览器插件。See 帮你看重点，Find 帮你找原文，Act 帮你在确认后定位章节或执行一次页面点击。

  1. 下载 JevLens v0.1.0 ZIP 并解压，无需编译。
  2. 在电脑打开 chrome://extensions，开启“开发者模式”，选择“加载已解压的扩展程序”，加载包含 manifest.json 的文件夹，保留该文件夹。
  3. 刷新已打开的网页，在 Chrome 扩展菜单找到 JevLens，固定到工具栏并点击图标，打开侧栏。
第一次使用可以保留默认 Demo：无需 Key，不发送 AI 请求。它使用本地规则，适合先熟悉操作；中文提问匹配英文文章等语义能力需要可用的真实模型。

目前尚未上架 Chrome Web Store；手动安装版需要重新下载并加载新版来更新。Chrome 内部页面和商店等受限制页面无法使用内容提取。

SEE / 02

看见重点，仍然读原文。

  1. 打开一篇有正文的网页，点击侧栏 See。
  2. 用 Sentence / Paragraph 选择按句或按段分析。
  3. 调整 Density 控制显示多少重点；点击结果卡片，跳到对应原文。

预期：正文出现高亮，侧栏显示可追溯的原文片段。See 不是自动生成的全文摘要，Demo 的规则排序也不代表 Jev 的语义质量。

FIND / 03

带着问题，回到答案所在的位置。

  1. 选择 Find，输入原文中的关键词，点击“查找”。
  2. 点击匹配卡片或使用箭头，逐条查看上下文；Escape 清除查找意图。
  3. 启用真实 AI 后，可尝试自然语言问题，例如“这个方法有什么限制？”。
Demo 入门：在英文 Rust 所有权章节输入 ownership。中文提问“什么是所有权？”需要真实模型做跨语言语义判断。

预期：找到原文片段并定位，不是给出聊天式回答。检索范围是当前已加载文档；不会跨网站搜索或自动展开隐藏内容。

ACT / 04

先看目标，再确认下一步。

章节导航：在 Act 的“本页目录”选择一个已有标题，点击“推荐”，核对目标后点击 Approve & go。也可以输入 go to 加目录中的准确标题。这种导航无需 API。

页面点击：输入页面中已有的按钮或链接名称，点击“推荐”，查看绿色光环是否指向正确控件，再点 Approve & click。Skip 换候选，Stop / Escape 取消。

Act 只执行确认后的单次动作。支付、删除、发送、授权、表单提交、输入和下载等识别到的风险操作需要你手动完成；它不会自己连续操作或完成整套流程。

目录仅覆盖当前页已加载的标题及同页目录锚点；跨页目录链接属于页面点击。它不会自动跨页读取章节、展开菜单或加载无限滚动列表。

PDF / 05

论文再长，也能按页和章节走。

  1. 通过侧栏 Open PDF 或页面右键 Open in Jev PDF Viewer，进入插件自己的 PDF 查看器。
  2. 等待 PDF 加载完成，在 Act 输入 go to page 10（文档需至少 10 页），点击推荐，再确认跳转。
  3. 输入 go to Appendix 或“跳到附录”；优先匹配目录书签，再尝试文字层短标题。无匹配时，使用本页目录的准确名称或改用 Find。

注意：Chrome 内置 PDF 阅读器中的文字和工具栏不能按普通 HTML 处理，需要先进入 Jev PDF Viewer。扫描件没有文字层时不能搜索，当前没有 OCR。远程文件打不开时可自行下载，然后在查看器选择本地文件。

本地 PDF 默认在本地处理；发送给 AI 需要额外允许。目录导航和页码跳转无需 API。

API SETTINGS / 06

选择自己的模型服务。

点击侧栏底部输入框上方的 API settings，选择 Jev Official、OpenRouter 或 Custom，填写自己的 Key 和模型。Test connection 使用固定样本检查连接；保存并允许发送页面内容后，真实 AI 分析才会启用。

方式 接口 / 默认模型
Jev Official https://api.typesafe.ai/v1/systemone
jev-latest
OpenRouter https://openrouter.ai/api/alpha/decisions
typesafe/jev-1.13
Custom 完整 Jev / Decisions 兼容地址，需支持 Score 和 Choice；不支持任意 Chat Completions 接口。

各服务的地址、模型和 Key 独立保存。测试和真实分析可能产生服务商费用；插件不附带共享 Key 或免费额度。设置界面的默认值以你安装的版本为准。

TROUBLESHOOTING / 07

没有结果时，从这里检查。

“No useful action in this viewport.”

这是未找到合适动作，不表示页面没有你要的内容。找信息用 Find；跳章节用 Act 的本页目录。页面点击只检查已加载 DOM 的前 200 个非隐藏控件，目标可能未加载、被折叠或未匹配。手动展开内容，使用实际标题或按钮名称再试。

PDF 中有 Appendix，却找不到？

先确认已经进入 Jev PDF Viewer 并加载完成。目录可能使用其他标题；尝试本页目录里的准确名称、Find 原文关键词，或直接跳到已知页码。正文提到 appendix 不等于存在可导航的附录标题。

插件打不开、页面没有高亮？

安装或更新后刷新页面；确认是允许读取的普通网页。浏览器内部页、跨域 iframe、编辑器、画布及隐藏内容可能无法提取。复杂 PDF 的文字顺序也可能不准确。

Key 报错、401 / 402 / 429？

401 / 403 检查 Key 和权限；402 检查服务商余额；429 稍后重试。确认接口和模型填写正确，使用 Test connection；不要把 Key 发到公开 Issues 或截图中。

中文问题找不到英文原文？

默认 Demo 使用本地规则，不提供可靠的跨语言语义匹配。先用原文关键词验证操作，再配置可用的真实 AI 服务测试中文问题。

YOUR READING, YOUR CHOICE / 08

知道数据去了哪里。

Demo 不上传页面。真实 AI 按你保存的许可将必要文本和意图发送到选定服务，敏感页面与本地 PDF 需要额外允许。Key 保存在当前浏览器扩展本地存储中，不云同步。

插件不绕过登录或付费墙，不做投资、法律或医疗判断，不解析视频画面。案例库中的价格、新闻和列表可能变化，应以你打开时的原文为准。
